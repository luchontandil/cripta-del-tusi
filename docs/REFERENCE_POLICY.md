# Búsqueda y uso de referencias y assets

Cuando una descripción pida una época, criatura, arquitectura, objeto o estilo desconocido, el agente debe buscar referencias web si la búsqueda está disponible. No es necesario buscar para cada asset que encaje claramente con la guía del proyecto.

## Flujo

1. Traducir el pedido en 2–4 consultas precisas: referencia visual, proporción/función y low-poly game asset open license si se busca reutilizar una malla.
2. Priorizar fuente primaria (página del artista/creador, repositorio oficial, documentación/licencia del propio asset); imágenes de juegos comerciales solo para análisis visual contextual.
3. Reunir hasta 3–6 referencias visuales variadas. Anotar qué se aprende de cada una (silueta, ensamblaje, desgaste, paleta, escala). No calcar una imagen ni mezclar rasgos en una réplica reconocible.
4. Si se reutiliza un modelo/texture, comprobar licencia **del asset exacto**, no asumir que todo un sitio tiene una sola licencia. Aceptar por defecto CC0, dominio público, CC-BY con atribución o licencia explícitamente compatible con el juego. Rechazar “free download” sin licencia clara, NC/ND si el uso lo contradice, assets ripped/datamined y fuentes pirateadas. No descargar ni integrar hasta verificar formato, licencia y atribución requerida.
5. Registrar en `docs/references/<asset-id>.md`: título, autor, URL exacta, fecha de consulta, licencia y versión, usos permitidos/obligación de atribución, checksum del archivo si se descarga, y si es inspiración o parte del producto. Copiar licencia/credit file junto al asset redistribuido.
6. Si no puede verificarse permiso, usarlo solo como referencia de análisis en enlaces; crear una alternativa original y declararlo.

## Catálogo inicial para modelos de juego

- [Kenney](https://kenney.nl/assets): paquetes de juego; el sitio afirma que sus assets son CC0. Confirmar el archivo LICENSE del paquete descargado.
- [Quaternius](https://quaternius.com/): packs low-poly; revisar FAQ/licencia y LICENSE incluido en cada descarga.
- [Poly Haven](https://polyhaven.com/): modelos, HDRI y texturas CC0 según su página de licencia.

Son puntos de partida, no garantías para todo archivo enlazado externamente. Registrar siempre la licencia del asset específico y conservar su atribución cuando aplique. No descargar automáticamente un pack entero ni incorporar assets solo porque sean gratis.
