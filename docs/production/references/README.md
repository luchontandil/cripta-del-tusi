# Referencias de producción visual

Guarda aquí las imágenes aprobadas en el chat **Crear concept art medieval**, con nombres descriptivos: `style_overview`, `guardian`, `archer`, `cleric`, `mage`, `ninja`, `crypt`, `jungle`, `hell`, `materials`, `equipment`, por ejemplo. Añade un `references.md` que indique qué corrige/fija cada imagen.

La lectura conectada del chat devolvió mensajes e image-group queries, no los bytes de las imágenes. Por tanto, Claude Code/Codex en el repo no pueden inspeccionar las referencias hasta que se guarden aquí. No escribir “revisado visualmente” si solo se consultó su prompt textual.

Usa las imágenes de Dofus y otros juegos como inspiración general de proporciones/legibilidad. No copies ni distribuyas personajes, modelos, texturas, UI ni concept art protegidos. Para modelos o texturas reutilizables, verificar la licencia del archivo exacto conforme a `docs/REFERENCE_POLICY.md`.
